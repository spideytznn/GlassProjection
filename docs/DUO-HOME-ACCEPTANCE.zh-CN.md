## 尚需补齐

1. 从当前真实 CLOSED 外屏展开到内屏，再折回外屏，检查图标/组件身份、页码与现有折叠动画是否衔接，并记录实际交接画面；不能用模拟窗口尺寸代替物理切屏。
2. 外屏完整 HomeSmoke 已通过：文件夹、搜索清空/空结果、真实键盘避让、组件选择器及现有组件 2×2/4×2 混排。供应商复杂配置表单仍按实际提供方补测；一次流程通过不代表所有提供方均通过。
3. 不同厂商私有组件扩展不因标准 API 通路通过而被视为全部通过。已覆盖独立配置 Activity 自动回传；复杂表单的手动完成、中途返回和重建恢复未逐一验证，后续按实际使用的提供方补充。
