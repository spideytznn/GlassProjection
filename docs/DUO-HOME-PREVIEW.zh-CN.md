# 玻璃桌面预览版

版本：0.5.0-preview.8 / code 95。此版本在原玻璃投影应用内增加可选的原生 Android HOME，不替换系统最近任务、小窗、分屏或应用内部导航。扩展屏连续显示留待后续专项。当前可安装包为 `dist/GlassProjection-0.5.0-preview.8.apk`，旁边提供 SHA256 校验文件。

## 本次修正

- preview.8 支持应用页图标与系统小组件混排。编辑模式点“＋组件”添加到当前页，已有左栏组件可移入应用页。初始尺寸采用组件声明的默认占格，调整选项遵守组件支持的缩放方向和尺寸范围；位置与尺寸持久保存。添加中断后可继续配置或重新选择，系统取消添加会释放临时组件并保留原布局。
- 原壁纸直接显示，仅玻璃控件区域着色和模糊。侧边 Dock 紧凑容纳四个常用应用，圆形搜索入口位于下方同一垂直中心线。桌面面板和菜单统一圆角、颜色、进入/退出动画，顶部编辑与设置合并为玻璃操作区。
- 翻页允许轻度斜滑，应用名称不再抢占横向滚动。四行图标按当前可用高度排布，移除应用网格外层多余的纵向滚动；组件内部滚动由组件处理。后台目录更新等待触摸与翻页动画结束后应用，保留最终页码。
- Duo 为默认 HOME 时，桌面不显示侧滑返回区域；从兼容手势进入小米最近任务后，左右侧滑回到 Duo 并播放进入动画。内屏及真实 CLOSED 外屏的双向真机验证均通过；其他最近任务入口继续由小米系统处理。

- preview.7 增加第三方 HOME 可用的兼容全面屏手势。左右边缘内滑调用系统返回，底部短上滑调用系统主页，上滑并停留调用系统最近任务；手势区域只占两侧 22 dp 和底部 40 dp，方向偏离时取消，并在确认动作时提供轻触觉反馈。锁屏和息屏时移除触摸区域。
- 设置页和桌面菜单增加全面屏手势入口。启用时由已配对的本机助手隐藏三键，手势识别由现有无障碍服务完成；关闭该功能或从系统设置停用本应用无障碍时恢复 `navigation_mode=0`、`force_fsg_nav_bar=0`。恢复顺序已在真机验证，先写回导航状态再关闭系统覆盖层，避免小米回收辅助进程造成半恢复。
- preview.6 修复空 Dock 初始化：补齐默认应用查询可见性及已安装应用回退路径，为尚未初始化的空 Dock 填入电话、浏览器、短信、相机；成功后记录初始化状态，之后主动移除图标不会被重新填入。常态 Dock 只显示常用应用图标，删除搜索与组件切换入口；添加按钮只在编辑模式且尚有空位时显示。窄屏的组件/应用切换移至对应面板标题。
- 内屏应用区取消重复标题占位，根据可用高度设置行高并预留名称空间；preview.8 将固定四行完整放入应用区域。真实 1168×1712 外屏已确认四行和名称完整，窄屏应用/小组件入口使用统一玻璃分段控件；极小自由窗口和放大字体仍需继续检查。
- 横屏大键盘出现、可用高度不足时暂时收起搜索/组件面板的大标题，将空间留给完整结果行；收起键盘后恢复标题和关闭按钮。
- preview.5 文件夹改为真实图标网格，搜索改为图标、应用名称与桌面位置列表，保留长按管理并增加可见的管理按钮。统一使用有圆角与背景模糊的有界对话框，根据系统栏、挖孔及键盘 Insets 限制面板尺寸；应用目录刷新会同步更新已打开的搜索结果。键盘搜索在唯一结果时选择应用，图标点击继续向系统提供真实图标位置。
- 小组件选择器也使用同一玻璃面板：显示组件名称、应用图标及应用名称，支持搜索组件名称、应用名称或包名。目录在后台读取，批量复用 LauncherApps 返回的应用信息；同一应用及资料的组件共享图标，只为可见条目异步解码。关闭面板会取消排队工作，返回 HOME 会一并收起选择器。选中后的标准系统绑定、授权、配置及现有组件实例处理保持原流程。
- preview.4 使用 AndroidX ViewPager 1.1.0 完成跟手滑动、惯性落页、箭头动画和无障碍翻页。相邻应用页按需缓存；普通翻页及正常返回桌面保持根布局、Dock、小组件树不变。关闭系统动画时，按钮和页码跳转直接到目标页。
- preview.3 修复设置入口闪退：旧更新比较器仅接受纯数字版本，缓存的正式版与已安装 `0.5.0-preview.2` 比较时抛异常。比较器现支持预发布标识和数字序号，正式版高于同号预览版，旧正式版低于新主版本的预览版；无法识别的当前版本不再使更新观察者崩溃。在线更新仍只接受正式 Release，包名、版本码与签名校验保留。此前直接启动 HOME 的测试未覆盖设置入口，现已补齐。
- 组件栏、应用区与 Dock 共用扣除系统栏后的可用高度，统一上下留白；移除侧栏的顶部外边距，避免撑满高度后底部圆角被裁切。
- 去掉顶部重复时钟，保留系统状态栏时间及组件栏日期。
- 应用目录加载完成前显示加载提示，避免已保存的图标短暂显示为“暂不可用”。
- 点击应用图标和 Dock 图标时向系统提供图标的屏幕坐标，动画选项继续由系统决定。
- 组件栏、Dock、搜索栏在支持的 HyperOS 上调用局部原生背景模糊接口；保留透明底色和圆角，图标、文字及组件内容不参与模糊。不支持接口、调用失败或系统关闭窗口模糊时保留半透明背景。

## 小米动画与玻璃效果的边界

当前是独立 HOME，翻页复用 [AndroidX ViewPager](https://developer.android.com/jetpack/androidx/releases/viewpager)，不能通过系统主题自动继承小米桌面的专属翻页效果。打开应用使用 `LauncherApps.startMainActivity`，未覆盖系统默认转场；提供图标坐标并不等于接入小米的图标展开、返回归位等远程动画。[Android 转场架构](https://source.android.com/docs/core/display/synched-app-transitions)说明此类联动由 Launcher / SystemUI 控制。

本机实测 `View.setBackgroundBlur(int, float[])` 与 `setBackgroundBlurAlpha(float)` 可用：系统为控件创建 `BackgroundBlurDrawable`，截图确认模糊只覆盖三个指定区域，应用区和内容清晰。这是 HyperOS 提供的局部系统模糊能力，不等于完整复用小米桌面仿生玻璃的所有参数、折射及动效。实现通过运行时检测接口兼容其他系统，监听窗口模糊可用性，控件卸载时解除监听；不依赖截图轮询或额外窗口。[Android 窗口模糊说明](https://source.android.com/docs/core/display/window-blurs)介绍系统模糊动态开关；本项目使用的局部 View 扩展仍按机型验证。

## 使用

打开玻璃投影设置页 → **打开桌面预览**。基础桌面无需连接助手或开启无障碍。已有折叠特效仍按原设置运行。

桌面右上角 **设置 → 选择默认桌面** 可进入系统选择界面；也可以从系统默认应用设置切回小米桌面。安装和打开预览不会自动修改默认桌面。

- 内屏宽窗口：左侧显示今天与小组件，右侧为应用页，最右侧为 Dock。窄窗口可用“组件/应用”切换，图标顺序共用。
- 左右滑动应用区域翻页；下方箭头或圆点也能切换。内外屏右侧区域使用四列四行，共 16 个网格位置，小组件按尺寸占用多个位置。内屏和真实 CLOSED 外屏均已实测。
- 点击图标启动真实应用。搜索覆盖手机可访问的应用和工作资料入口；工作资料暂停或应用已卸载时可能暂不可用。
- 长按图标拖动：落在另一图标中心可合并文件夹，落在左右边缘调整顺序，拖到 Dock 添加常用应用。拖动只在本桌面内处理，不注册新的系统分屏手势。
- 点击“编辑”，再点图标，可调整顺序、移到其他已有页面、添加到 Dock、建立文件夹或移除桌面入口。移除入口不会卸载应用；搜索中长按应用可重新添加。
- 文件夹内长按应用可移出或添加到 Dock；编辑模式可重命名、解散文件夹。Dock 最多四项，长按可排序或移除。
- “添加现有小组件”可搜索本机提供项；由系统请求绑定授权，并打开组件自己的设置。原小米桌面上的组件实例不被移动或删除。
- 组件由原应用提供内容。编辑模式下可调整组件高度、顺序、打开组件配置或移除；标准更新通道由 `AppWidgetHost` 接收。
- 壁纸沿用系统壁纸，也可通过菜单打开系统壁纸设置。
- 原生小窗/分屏：从小米最近任务长按支持的应用卡片，使用系统的小窗入口；小窗顶部的窗口菜单可切换左右分屏。当前设备上，计算器切到左侧后，点击 Duo Dock 的浏览器图标即可由系统放入右侧。窗口菜单也能恢复全屏。并非所有应用都支持这些模式。
- 兼容全面屏手势：先连接助手并开启无障碍，再在设置页点击“启用全面屏手势”。左右边缘内滑返回；底部上滑回桌面；底部上滑并停留打开小米最近任务。需要恢复按键时点击“恢复三键导航”，或在系统中停用玻璃投影无障碍服务。

## 已实现与待验证

已实现应用目录、真实启动、分页与搜索、排序与文件夹、Dock、布局持久化、内外窗口自适应，以及小组件的枚举、用户授权绑定、配置、更新承载、移除和高度设置。设置页增加了预览入口，场景识别能区分同包的桌面页和设置页，现有投影数学和助手 DEX 未修改。

自动测试覆盖桌面和文件夹持久化、工作资料标识、小组件绑定事务的恢复、实际应用与组件目录、原生图标网格和编辑开关。纯 JVM 测试覆盖 1500 次排序/文件夹操作的数据守恒、移除入口不被目录刷新重新添加、Dock 容量和分页边界。

测试设备 `lhasa / HyperOS 4.0.11.0 / Android 17` 已成功枚举 168 个应用入口和 649 个组件提供项，并通过初轮原生网格和编辑测试。数量只代表当前设备枚举结果，不代表全部组件都完成绑定与更新验证。

补充实测：小米日历 `SmallDateWidget` 已通过搜索选择、绑定、显示日期/星期，并确认点击后打开原生日历 `AllInOneActivity`；覆盖安装和进程重新启动后仍保留该组件实例。组件尺寸更新使用非空 Bundle，并将提供方的像素尺寸转换为布局 dp。当前只确认此样本的显示与点击，不将其视为所有小米扩展刷新能力已验证。

仍需逐项实机体验：

- 小米组件的实际点击、持续刷新与私有扩展能力；当前接入标准 Android Widget 通道，不保证小米组件中心、曝光刷新等扩展完整继承。
- 兼容手势已完成导航动作和恢复保护，但不具备小米系统桌面 Quickstep 的私有远程转场；返回、主页和最近任务由系统全局动作执行，不能承诺图标缩回等小米桌面专属动画。
- 实际快速开合、组件跨屏尺寸适配、半折操作，以及持续使用的帧率和功耗。

首版应用按紧凑顺序自动分页，尚不提供任意空格布局、独立空白页或 iOS 系统界面复刻。图标和小组件使用已安装应用提供的内容，不含 Apple 图标素材。

## 开发验证

preview.6 原生多任务专项：设备保持 Duo 为默认 HOME、三键导航、无障碍全局值 0。系统任务键打开 `com.miui.home/.recents.RecentsActivity`；长按计算器卡片后，系统菜单提供小窗/分屏入口，选择小窗后任务成为 `mode=freeform`，Duo 桌面仍在后方显示。通过系统窗口顶部菜单选择左侧分屏，计算器任务进入 `mInSplitScreen=true`、边界 `[0,0,1170,1672]`；随后点击 Duo Dock 中的浏览器，系统自动将浏览器加入右侧 `[1194,0,2364,1672]`，两侧均为系统 `multi-window` 任务。通过窗口菜单恢复全屏后，计算器为 `mode=fullscreen`、两个分屏容器为空，系统 HOME 键正常返回 Duo。没有新增或修改小窗/分屏代码。

边界记录：系统设置/WLAN 的任务菜单显示不支持小窗及分屏，这是该应用的能力限制；未将其算作桌面故障。一次拖动分隔条没有改变最终宽度，因此本轮只确认分屏建立与退出，不宣称任意比例调整通过。测试未修改导航模式、默认 HOME 或无障碍状态，也未清理用户的最近任务或输入计算内容。

preview.6：主包和辅助包已安装，最终构建及 lint 通过（0 错误、40 警告），全部 JVM 模型测试通过。手机端完整 `HomeSmoke` 通过，新增断言覆盖非空常用应用 Dock、Dock 仅含应用图标、三行无需上下滚动且名称未被裁切；文件夹、搜索清空/空结果/唯一选择、组件选择与取消、真实键盘下至少一条完整结果均通过。最终截图复核了 Dock、三行应用和两个键盘面板。

preview.7 全面屏手势专项：保持玻璃桌面为默认 HOME，通过真实触摸注入分别记录 `ACTION BACK`、`ACTION HOME`、`ACTION RECENTS`。主页动作回到 `DuoHomeActivity`；最近任务动作打开小米原生 `com.miui.home/.recents.RecentsActivity`。随后从系统已启用无障碍列表移除玻璃投影，应用偏好自动变为关闭，`force_fsg_nav_bar` 从 1 恢复为 0、`navigation_mode` 从 2 恢复为 0，gestural overlay 关闭，三键重新出现。重新启用服务和兼容手势后再次用底部手势返回 Duo，最终设备保留兼容手势状态。

系统导航设置仍会提示“非系统桌面不支持使用全面屏手势”，因此本实现没有冒充或 Hook 小米系统桌面。它使用窄透明无障碍覆盖层判断手势，再调用 Android 系统全局动作；小米最近任务、小窗和分屏代码没有修改。[AnyLauncher 原始项目](https://github.com/tiann/AnyLauncher)所示路线依赖 Xposed 且存在动画限制，本项目未安装 Root/Xposed 模块。
