# 玻璃投影 · GlassProjection

为小米折叠屏制作的玻璃开合动画：把屏幕想象成正在翻开的玻璃，画面像玻璃下方的一张纸，随着铰链角度产生投影与渐变模糊。

开发中的 **0.5.0-preview.9** 新增可选的玻璃桌面，支持常用应用 Dock、跟手分页、图标文件夹、应用搜索和现有 Android 小组件；桌面网格升级为澎湃OS 风格四列五行，并支持从 MIUI 原生桌面一键迁移应用、文件夹（含内部应用）与小组件排布。新增 iOS 风格下拉体系：顶部下拉呼出通知中心/控制中心（可跨应用呼出），支持淡入淡出翻页、惯性轻甩切换、上滑收起、边缘横滑返回，控制中心含 Wi-Fi/蓝牙/流量/飞行模式等圆形开关与亮度/音量滑条。兼容全面屏手势支持左右内滑返回、底部上滑回桌面、上滑停留打开小米最近任务；桌面停用侧滑返回，最近任务侧滑可平滑返回桌面，并在停用无障碍时恢复三键。使用范围与实测情况见[桌面预览说明](docs/DUO-HOME-PREVIEW.zh-CN.md)。以下发布版本说明保留原动画版本的使用信息。

## 功能

- **实时桌面投影**：使用系统画面的实时镜像，动态桌面内容可以持续更新。
- **内外屏分别处理**：内屏左半侧产生视差和模糊，模糊跨过中轴线在另一半逐渐收尾；外屏保留纸张边缘和连续虚化。
- **随距离变化的模糊**：包含黑色边缘的柔和过渡；模糊强度可调。
- **自定义动画起点**：默认从 1° 开始渐入，可调 1–30°；测试机型用接触分离状态区分小角度展开与完全合拢。
- **自定义切屏角度**：展开和合拢分别设置，支持中途反向开合。
- **可调拉伸与裁切**：默认 100%（30° 裁切约 12%），范围 0–125%，线性跟随角度。
- **切屏渐变**：内外屏在实际切屏角度前最多约 8° 开始渐暗，布局和源帧稳定后用 120 毫秒渐亮；切屏角度设置仍控制实际切换。
- **应用黑名单**：带应用图标与搜索，选中的应用不参与动画。
- **检查更新**：从 GitHub Release 下载 APK，支持镜像换源、完整性与签名校验；全部下载失败时提供发布页链接。进入应用自动检查并显示更新红点，下载由用户点击启动，支持后台下载、暂停与断点续传。
- **空闲优化**：画面透明后暂停捕获和持续绘制，减少重复状态更新，重新开合时唤醒。
- **可选全局启用**：默认作用于桌面与亮屏锁屏；开启「作用范围 → 全局启用」后，在应用内也显示开合效果。
- **悬停恢复正常**：角度摆幅不超过 10° 持续达到设定时间后，平滑回放至正常画面；等待时间可调 1～10 秒，默认 3 秒。
- **手指滑动恢复**：可选直接检测手指滑动，静态页面也可触发，轻点不触发。两种恢复之后，继续开合超过 10° 会重新跟随铰链。
- **本机无线启动**：一个「配对」按钮，自动发现本机地址和端口；已有有效配对时无需重复操作，认证失效时进入重新配对。
- **系统小窗配对**：配对小窗与无线调试页面同时显示，小米可直接进入无线调试，无需通知栏输入配对码。
- **物理闭合保护**：在支持的测试固件上，完全合拢时忽略倾斜引起的异常铰链读数，避免误触发模糊；增加进程退出时的投影层回收。
- **内屏平展保护**：已展开信号与 ≥175° 读数共同锁定，锁定后倾斜不重新触发动画，确认重新折叠后恢复跟随。
- **后台运行**：设置页不显示在最近任务中，退出设置页不会暂停动画。

当前没有陀螺仪或眼睛追踪。透视变化来自铰链角度。渲染请求 120 Hz，实际帧率受系统、GPU、温度与屏幕刷新率影响。

## 安装与使用

1. 升级用户先在旧版点 **暂停动画**，确认本应用无障碍已关闭。从 [Releases](https://github.com/spideytznn/GlassProjection/releases) 下载 `GlassProjection-0.4.30.apk`；按上方签名说明决定覆盖安装或记录参数后重装。
2. 覆盖升级后重新检查无障碍服务。若早期版本遗留锁屏 / 桌面投影层，重启手机后再连接助手。
3. 若没有开发者选项，小米进入 **设置 → 我的设备 → 连续点击 OS 版本**，直到提示进入开发者模式。开启无线调试；小米还需要单独开启 **USB 调试（安全设置）**。
4. 打开 **玻璃投影**，点 **配对**。没有记录时会打开配对小窗并跳到无线调试；在系统中选择使用配对码配对设备，把 6 位码填入小窗。应用自动连接并启动助手。已有有效记录时会提示无需重复配对。此前仅在 Shizuku 中配对过的用户，仍需为玻璃投影完成一次独立配对。
5. 助手连接成功后，点 **开启无障碍**，在系统设置里开启 **玻璃投影**。如果系统提示“受限设置”，按系统提供的应用信息入口允许后再开启。
6. 为玻璃投影开启 **自启动**、将省电策略设为 **无限制**，并加入小米的 **后台锁定 / 清理保护**。
7. 返回应用，确认显示 **动画已就绪**，再回到系统桌面，从完全合拢开始缓慢展开、合拢体验。

若安装过早期「折叠玻璃」或其他桌面开合实验应用，请先关闭它们的无障碍服务，避免叠加。

| 设置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 模糊强度 | 100% | 0–200% |
| 动画起始角度 | 1° | 1–30° |
| 拉伸与裁切强度 | 100% | 0–125% |
| 展开时切到内屏 | 60° | 10–170° |
| 合拢时切到外屏 | 120° | 10–170° |
| 全局启用 | 关闭 | 开 / 关 |
| 悬停等待时间 | 3 秒 | 1–10 秒 |
| 滑动恢复正常画面 | 关闭 | 开 / 关 |

0° 表示合拢，180° 表示展开。设置会自动保存。0% 模糊仍保留投影几何；若要完全停用，点击 **暂停动画**。暂停会关闭本应用的无障碍服务，并释放自定义切屏请求，让系统恢复自己的切屏策略。

悬停或滑动触发后，效果约用 220 毫秒快速回放至正常；只退出视觉效果，仍保留当前作用范围内的切屏角度控制。

更多说明见 [使用教程与故障排查](docs/USAGE.zh-CN.md)。

## 后台与重启

- **退出玻璃投影界面**：不会主动停止后台动画。
- **一键清理**：测试设备在配置自启动、无限制省电和后台锁定后已验证继续运行；不保证其他系统的清理策略相同。
- **强行停止应用、关闭无障碍**：需手动恢复对应服务。
- **重启手机**：重新开启无线调试并打开玻璃投影，应用会使用保存的身份尝试连接，再检查无障碍状态。授权仍有效时不需要重新配对。

本项目不会偷偷重新打开用户主动关闭的无障碍服务，也不承诺“永不被杀”。

## 已知限制

- 使用 Android 隐藏接口和设备特定的显示状态，系统升级可能影响兼容性。当前固定输出画布、方向映射与状态编号需要针对其他设备重新适配。
- 保留系统单屏切换路线，没有启用内外屏常亮或双屏镜像桌面。
- 切屏使用提前渐暗、黑底和渐亮减少系统重排的可见跳变。布局就绪采用尺寸/方向及新帧的启发式判断，系统迟到更新或快速反向时仍需实机验证；等待有超时退出。
- 不对 DRM、安全窗口或其他禁止捕获的画面承诺投影能力；锁屏支持仅指测试设备上可取得的亮屏锁屏画面。
- 持续镜像和 GPU 模糊会增加耗电、发热。全局启用会扩大效果的作用范围。
- 手指滑动观察需要系统提供对应接口和 shell 观察权限，不支持时仍可使用悬停计时恢复。

## 从源码构建

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0；项目内置 Gradle 8.7 Wrapper。

```sh
git clone https://github.com/spideytznn/GlassProjection.git
cd GlassProjection
# 配置 JAVA_HOME 和 ANDROID_HOME，或为 Gradle 配置 local.properties 中的 sdk.dir
./gradlew :projection-lab:assembleDebug :projection-lab:lintDebug
```

Windows 使用 `gradlew.bat`。产物位于：

```text
projection-lab/build/outputs/apk/debug/projection-lab-debug.apk
```

仓库包含两份经过实机验证的助手 DEX 及其完整 Java 源码。修改 `tools/helpers/` 后，须先运行 `python tools/build_helpers.py` 更新内置 DEX，再构建 APK。`python tools/build_helpers.py --check` 可以校验源码重建结果；`python tools/test_models.py` 运行几何、场景和切屏方向测试。

**v0.4.30 Release 附件是基于 `main` 的 debug 构建 APK，与 v0.4.27 测试版同签名，与 GitHub v0.4.11 / v0.4.16 / v0.4.17 不同。** 附件提供 SHA-256 校验值。自己构建的 debug APK 通常使用不同密钥，可能无法直接覆盖安装 Release。仓库不提供私钥或本机调试密钥。历史附件及签名说明仍见[构建说明](docs/DEVELOPMENT.zh-CN.md)。

## 隐私与权限

应用声明网络权限，用于本机 mDNS 发现和回环地址上的无线 ADB 配对、连接；没有账号、广告、分析或上传服务。配对身份保存在应用私有且不备份的目录，配对码不写文件或日志。画面在手机本地处理；当前默认实时路径不建立桌面分页截图缓存。仓库中的 PNG 是原创编号测试图，不是用户桌面截图。

无障碍用于桌面/锁屏场景判断、铰链协调和显示动画覆盖层；保留的兼容路径使用系统截图能力。本机无线 ADB 启动有 shell 权限的实时镜像与设备状态控制助手，握手完成后断开启动连接。触点仅在内存中判断位移，不保存或上传。旧 Shizuku 兼容代码仍在 APK 中，界面不再提供备用入口；默认配对小窗无需通知或悬浮权限，通知配对在「更多配对方式」中保留，悬浮窗配对已删除。更新下载只访问本项目 Release 及镜像，不上传配对信息、画面或黑名单。详见[本机无线启动](docs/WIRELESS-SETUP.zh-CN.md)和[开发说明](docs/DEVELOPMENT.zh-CN.md)。
